Architecture

Loading checkpoint dimensions…

Tokenize English

Split the sentence into subwords using bilingual BPE. Add sinusoidal positions to the token embeddings.

Encoder

Self-attention combines information across the English sentence. A feed-forward network transforms each position.

Decoder

Masked self-attention reads the Hindi prefix. Cross-attention reads the encoded English before the feed-forward layer.

Generate Hindi

Score the vocabulary, choose a token, and repeat until the model emits EOS or reaches the length limit.

Scaled dot-product attention

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V

Scale query–key scores by the square root of the head width. Mask disallowed keys before softmax.

Multi-head attention

Q,K,V → parallel heads → concat → projection

Each head learns its own projections. Concatenate and project the head outputs.

Causal masking

BOS → [✓ ·]   y₁ → [✓ ✓]

Each target query can attend to earlier positions and itself.

Cross-attention

Q from Hindi · K and V from English

Each Hindi position can attend to the entire English input.

Teacher forcing

Input [BOS, y₁, y₂] → labels [y₁, y₂, EOS]

Train on the reference prefix and predict the next token. Exclude padding from the loss.

Autoregressive inference

BOS → ŷ₁ → ŷ₂ → … → EOS

At inference, the decoder uses its own previous predictions.
